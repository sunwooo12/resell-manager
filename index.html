DB 마이그레이션 (최초 1회)
Supabase → SQL Editor에서 아래 쿼리를 실행하세요:
ALTER TABLE items ADD COLUMN IF NOT EXISTS quantity INT DEFAULT 1; ALTER TABLE items ADD COLUMN IF NOT EXISTS sold_quantity INT DEFAULT 0; ALTER TABLE items ADD COLUMN IF NOT EXISTS category TEXT DEFAULT '기타'; ALTER TABLE items ADD COLUMN IF NOT EXISTS brand TEXT DEFAULT ''; ALTER TABLE items ADD COLUMN IF NOT EXISTS product_code TEXT DEFAULT ''; ALTER TABLE items ADD COLUMN IF NOT EXISTS order_url TEXT DEFAULT ''; ALTER TABLE items ADD COLUMN IF NOT EXISTS storage_date DATE; ALTER TABLE items ADD COLUMN IF NOT EXISTS storage_start_date DATE; ALTER TABLE items ADD COLUMN IF NOT EXISTS shipping_cost INT DEFAULT 0; ALTER TABLE items ADD COLUMN IF NOT EXISTS other_cost INT DEFAULT 0;
데이터 점검 (추가판매 중복집계 버그)
"추가판매" 버튼으로 부분판매를 여러 번 한 항목 중, 월별 순수익 집계가 잘못됐을 수 있는 항목을 찾아 화면에만 표시합니다. 데이터는 수정하지 않습니다.
